# Portfólio Pessoal — Julio

## Sobre o projeto

Este projeto consiste no desenvolvimento de um portfólio pessoal com o objetivo de apresentar minha trajetória acadêmica, meus interesses, conhecimentos e projetos desenvolvidos durante minha formação em Análise e Desenvolvimento de Sistemas.

O site foi desenvolvido utilizando HTML, CSS e JavaScript, com uma interface minimalista, moderna e responsiva.

## Tecnologias utilizadas

- HTML5 — estruturação do conteúdo.
- CSS3 — estilização e responsividade.
- JavaScript — funcionalidades e interatividade.

## Funcionalidades

- Apresentação pessoal.
- Seção sobre mim.
- Apresentação de interesses pessoais.
- Exibição de conhecimentos e tecnologias estudadas.
- Galeria de projetos acadêmicos.
- Alternância entre tema claro e escuro.
- Menu de navegação responsivo.
- Animações suaves durante a navegação.
- Links para projetos hospedados no GitHub.

## Projetos apresentados

### Sistema de Oficina Mecânica
Projeto acadêmico de modelagem e organização de banco de dados utilizando MySQL.

### Conversor de Temperatura
Programa desenvolvido em linguagem C para realizar conversões entre diferentes escalas de temperatura.

### Sistema de Controle de Estoque
Projeto desenvolvido em Python para gerenciamento e organização de produtos, atualmente em desenvolvimento e aperfeiçoamento.
